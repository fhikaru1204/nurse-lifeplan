# 看護師のためのライフプラン試算（自社Webアプリ）

2026-09-11 作成。Threads → LINE → **この試算** → 面談、の踏み台。詳しい仕様は `../シミュレーション_設問案.md`、参考表の出典は `../data/相場_*.md`。

## 構成（静的サイト・サーバー不要）

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の器（ALTロゴ・ヘッダー） |
| `style.css` | ALTカラー（ネイビー #262f3c → ブルー #2269a0、アクセント #0984e1、差し色 #828245） |
| `data.js` | 参考表の数字と計算パラメータ（出典は data/相場_*.md） |
| `app.js` | ページ定義・描画・保存（端末に自動保存）・簡易試算・送信 |
| `config.js` | **公開前に設定**：GASの受け口URL・LINEのURL |
| `privacy.html` | 個人情報の取り扱い（同意チェックのリンク先） |
| `manual.html` | 面談ページの説明書（社内用）。各カード・列・パネル項目の意味、計算の前提と出典、お客さんへの言い方、1回目／2回目の進め方 |
| `gas/Code.gs` | 回答の受け口（スプレッドシート保存＋光さんにメール通知。メールに面談用ページのリンク入り） |
| `calc.js` | 計算エンジン（結果ページと面談用ページで共用） |
| `admin.html`（1回目）/ `proposal.html`（2回目）/ `admin.js` / `admin.css` | **面談用の詳細ページ**（社内用）。1回目は働き方の調整（夜勤・時短・転職・分担）だけ、2回目の提案ページで積立・家賃収入の欄が加わる（1回目に提案要素を見せて警戒されないため）。通知メールのリンク（回答をURLに埋め込み）か、rawシートのJSON貼り付けで表示。回答の要約・年ごとの収支表・働き方パターン比較（回答どおり／今すぐ夜勤をやめる／夜勤を60歳まで／時短6年／転職）とグラフ・提案レバー（積立の月額と利回り・家賃収入）。データは端末内でのみ計算し送信しない。印刷/PDF対応 |

## 画面の流れ

0 はじめに（同意チェック）→ 1 あなたのこと（氏名・生年月日・住所・勤務先・雇用形態・勤続・年収・役職・勤務形態・夜勤回数・住まい・家賃補助・世帯）→ 2 結婚（参考表：規模別費用）→ 3 子ども（参考表：進路別教育費・出産・育て方チェック）→ 4 マイホーム（参考表：価格・月返済・維持費と修繕・賃貸一生）→ 5 ライフスタイル（旅行回数と予算・車・趣味）→ 6 働き方（参考表：働き方別年収・退職金）→ 7 今のお金（借入・預貯金・資産は金額入力／資産形成・保険・不安はチェック）→ 8 老後（参考表：年金と生活費・どんな老後か・希望生活費は世帯の額）→ 9 結果（判定＋「入る−出る＝残る」の縦の式＋老後の目安＋タイムライン → 面談希望の選択 → 送信）

- 入力は原則チェック式。金額入力は借入・預貯金・資産・家賃/ローン月額・車のローン月額・子の年齢だけ
- **1人1回（2026-09-17）**：結果を一度表示するとその端末はロック（回答変更・やり直し不可）。社内用に ?unlock=1（回答を残してロックと送信済みだけ解除）
- 便利URL：末尾に ?reset=1（端末の回答と残した条件を全消去）／ ?debug=1（結果ページに内訳表）／面談ページ右上「回答データをコピー」
- 結果は超簡易。内訳と対策は面談（1回目＝詳細報告とプラン、2回目＝提案）
- 途中で閉じても続きから（localStorage）

## 公開手順（光さんの作業は 3 か所）

### 1. GAS（回答の受け口）
1. Googleスプレッドシートを新規作成 → 拡張機能 → Apps Script
2. `gas/Code.gs` を貼り、`SHEET_ID`（URLの /d/ と /edit の間）と `NOTIFY_TO` を書き換え
3. デプロイ → 新しいデプロイ → ウェブアプリ → 実行ユーザー「自分」・アクセス「全員」→ デプロイ → `/exec` のURLをコピー
4. `config.js` の `endpoint` に貼る（`lineUrl` に公式LINEのURLも）

### 2. ホスティング（GitHub Pages）
- リポジトリ `fhikaru1204/nurse-lifeplan` に `lifeplan/` の中身を置き、Settings → Pages で公開（**GitHub Free では private リポジトリの Pages は使えない→ public で作る**。静的ファイルのみで秘密情報なし。GAS の URL はブラウザから呼ぶので隠せないもの）
- `CNAME`（plan.alt-llc.jp）と `.nojekyll` は配置済（2026-09-16）
- カスタムドメイン：`plan.alt-llc.jp`（2026-09-16 確定）を Pages に設定
- **DNS（お名前.com / GMO）**：`plan` の CNAME を `fhikaru1204.github.io` に向ける。これだけ

### 3. LINE公式
- リッチメニュー or 挨拶メッセージに試算のURLを置く

## 計算の前提（2026-09-12 v3・年収ベースの年ごと収支）

- 年収（2026-09-14 変更）：**フルタイムで働き続けたときの伸び率を今の年収に複利で掛ける**（〜34歳 +1.5%/年・35〜44歳 +1.0%・45〜54歳 +0.5%・55〜59歳 0%・`data.js` wageGrowth）。根拠＝同一病院の初任給→勤続10年 +16%（病院看護実態調査2025）と年齢カーブの帯間の伸び。統計の年齢カーブは横断面（産休・時短の混在で30代前半が凹む）なので個人の年収には使わず、結果ページの参考表と60歳以降の再雇用の低下率（59歳比）にだけ使う。夜勤をやめる年から−15%、産休育休予定ありなら子1人につき3年間−37.5%。手取り＝年収×0.77
- 生活費（2026-09-13 変更）：**結婚まで**＝今の手取り−貯金−旅行−自分のためのお金（今の使い残し・家賃込み・年収に連動させない・購入の年から今の家賃分を落とす）。**結婚後**＝統計の一人あたり生活費（家計調査2025 単身勤労者 消費支出19.15万−住居3.03万−教養娯楽2.42万＝13.7万/月。**回答の住所（なければ勤務先住所）からエリアを判定して、参考表の「大人一人あたり」を初期値にする**[東京都区部15.0／関東14.6／全国13.6 等・判定不能なら全国13.7]・面談パネルで上書き可・パネル内にエリア別参考表あり）×世帯倍率（1.9＋同居の子1人につき0.2・1.9は住居除きベースの単身→夫婦比・2026-09-13）＋今の家賃（購入まで）を家計の分担で割る
- 自分のためのお金（趣味・推し活・美容）：設問の月額×12を、年収と同じ割合で増減させる。分担しない
- 家計の分担（既婚・同棲・結婚希望あり）：全部100%／自分が多め70%／半々50%／相手が多め30%。生活費・出産・教育・住まい・車・旅行にかける。結婚予定の人は結婚の年から。**産休育休で収入が落ちる年は手取り比に自動調整**（半々→39%・7割→59%・3割→21%。opts.shareAuto=false で無効。2026-09-13）
- 毎年引くもの：旅行（回数×1回の予算×人数[結婚後2人＋同居の子0.5/人・2026-09-14]×分担）、趣味（月額×12）、住まいのローン（借入＝予算＋諸費用8%−頭金［設問］・金利1%・35年、購入年から×分担。2026-09-13 諸費用をローンに組み込む方式へ）、教育費（**子の年齢ごとに段階別の年額**：0〜2歳 保育料36万、幼稚園〜高校は学校費＋塾・習い事の平均、大学は進路別＋一人暮らし105.5万。塾・習い事はチェックしたものだけを実費相場で計上（何も選ばなければ統計の平均）。受験対策は受験学年・留学は高2に一時計上。児童手当を年ごとに差し引き。2026-09-12 変更・22年均等から段階別へ）、車（持っている人＝今のローン返済を残り期間まで＋買い替えの年に予算を一時計上／欲しい人＝欲しい時期に最初の1台、以後買い替えペースごと。支払い方が一括なら購入年に全額、ローン5年／7年なら購入年から均等払い・金利なし。分担あり）
- 一時支出：結婚（自己負担中央値＋199万）×分担、出産35万×人数×分担、住まいの頭金（設問の額）×分担（諸費用はローン側）
- 退職金の目安：常勤で60歳以上まで働く人のみ。勤続（今の勤続＋60歳までの年数。転職ありなら転職の年[面談パネルで指定・既定は来年]から60歳までだけ・転職前の分は入れない。年収は転職で変えない＝2026-09-15に−5%撤回）に応じて58歳時点の月給×24／14／8／2.5か月分。**税引後で計上**（退職所得控除：勤続20年以下40万×年[最低80万]・20年超800万＋70万×(年−20)、超過分の1/2に所得税[速算表×1.021]＋住民税10%）。年ごとの表の**65歳の行＝退職金を受け取る年**（年収欄に額面・手取り欄に税引後・その年の生活費等も引く・貯金は積まず余りは全額残高へ・2026-09-14）

## JS/CSS の更新が反映されないとき（キャッシュ対策・2026-09-14）
- 各 html の `<script src="calc.js?v=20260914a">` のように **?v=日付** を付けている。ファイルを直したら全 html の `?v=` を同じ新しい値に上げる：
  ```bash
  cd nurse-threads/lifeplan && sed -i -E 's/\?v=[0-9a-z]+"/?v=20260915a"/g' *.html
  ```
- 上げ忘れたときはブラウザで Ctrl+Shift+R（スーパーリロード）
